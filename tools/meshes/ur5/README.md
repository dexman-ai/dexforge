# UR5 meshes

Collision meshes of the Universal Robots UR5 from
[Gepetto/example-robot-data](https://github.com/Gepetto/example-robot-data)
(`robots/ur_description/meshes/ur5/collision/`), the same model our `ur5.urdf`
was built from. BSD 3-Clause, Copyright (C) 2018-2020 LAAS-CNRS, University of
Edinburgh, INRIA.

They are used by `tools/visualize_ik.py`. File names match the URDF mesh names
(`base`, `shoulder`, `upperarm`, `forearm`, `wrist1`, `wrist2`, `wrist3`).
